What am I looking at?

Two zones. EVENT LOOP (top) is one thread — only ONE async request runs at a time, the rest wait at an await. THREADPOOL (bottom) is sync endpoints on worker threads, where several truly run at once.

●RUNNING — executing right now (on the loop, or on a worker)
○WAITING — parked at an await
⋯UNTRACED — the loop is in library code outside your roots, so we can't see it
✓DONE — request finished (stays until you clear)
🔥BLOCKED — sync/CPU work in an async path, freezing the loop
glowing spine dot = which request holds the loop
#each request's short id — one row = one request
